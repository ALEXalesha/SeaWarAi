# Морской бой против ИИ

**Морской бой по русским правилам против ИИ, который считает, где вероятнее всего стоят ваши корабли. Ваше поле ИИ не видит: ему достаются только результаты его выстрелов, и это проверяет закон-тест.**

## Правила

- Поле 10 × 10, буквы А-К (без Й) и цифры 1-10.
- Флот: один четырёхпалубный, два трёхпалубных, три двухпалубных, четыре однопалубных. Корабли не касаются друг друга даже углами (опция разрешает касаться углами).
- Попал - стреляешь ещё. Клетки вокруг потопленного корабля отмечаются сами.
- Опция «залп»: за ход столько выстрелов, сколько у тебя кораблей на плаву.
