# SeaWarAi: морской бой против ИИ

Игра из ИИ-Игротеки на Python. Общие правила — `PythonAiGames/docs/contract.md` (общая папка Игротеки), очередь — волна 3.

## 1. Игра

- Поле 10×10, буквы А–К (без Й) и цифры 1–10.
- Флот по русским правилам: 1 четырёхпалубный, 2 трёхпалубных, 3 двухпалубных, 4 однопалубных. Корабли не касаются друг друга даже углами.
- Попал — стреляешь ещё. Вокруг потопленного корабля клетки отмечаются сами.
- Расстановка:
  - мышью: перетащить, повернуть правой кнопкой;
  - «случайно».
- Опции: классические правила (касаться углами можно) и «залп» (несколько выстрелов за ход).

## 2. ИИ

1. **Стрельба — карта вероятностей.**
   - Перебор, а при большом числе раскладок Монте-Карло, всех расстановок оставшихся кораблей, согласных с промахами, попаданиями и правилом «не касаться».
   - Вероятность корабля в каждой клетке; стреляет туда, где она выше.
   - Сразу учитывается, что вокруг потопленного пусто.
2. **Привычки игрока.** ИИ запоминает, где Алексей обычно ставит корабли: по краям, в углах, однопалубные в центре. Эта статистика из прошлых партий подмешивается к карте вероятностей. Хранится в `ctx.data_dir`, можно сбросить.
3. **Расстановка ИИ:** не повторяет шаблоны, которые легко угадать. Учитывает, как стреляет игрок: если игрок начинает с центра, ИИ реже ставит туда. Проверка: против стрелка с картой вероятностей расстановка ИИ живёт дольше случайной.
- **Честность:** стреляющий ИИ не видит поле игрока, только результаты выстрелов. Закон-тест: перестановка кораблей игрока, согласная с теми же результатами, не меняет следующий выстрел ИИ.
- **Уровни:**
  - новичок — случайные выстрелы и добивание;
  - средний — «охота и добивание» с шахматным шагом;
  - сильный — карта вероятностей и привычки.
- **«Мысли ИИ»:** тепловая карта вероятностей на твоём поле — куда ИИ хочет выстрелить.

## 3. Проверки силы

- Среднее и медиана числа выстрелов до победы над случайной расстановкой, по 10 000 партий, для каждого уровня.
- Ориентир для сильного — около 45 выстрелов и меньше. В README настоящая цифра.
- Сильный против среднего: доля побед.

## 4. План

1. Каркас по контракту.
2. Правила, расстановка, проверка касаний.
3. Карта вероятностей: точная на малых случаях, закон честности.
4. Привычки игрока и расстановка ИИ.
5. Окно: два поля, расстановка мышью, анимации выстрелов, звук, «Мысли ИИ».
6. Тесты окна offscreen.
7. Выпуск после «да» Алексея: Gitea, потом свой GitHub (если Алексей его создал) и в составе AiGameRoom.
